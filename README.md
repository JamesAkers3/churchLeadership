# Church Leadership Advisory Project

This repository preserves the complete working record for James Akers' Christ-centered church advisory endeavor: the calling, research, frameworks, visual concepts, current PDFs, archived versions, source artwork, build files, previews, and quality-assurance history.

## Start here

Read [`PROJECT-CHECKPOINT.md`](PROJECT-CHECKPOINT.md) first. It records the heartbeat of the work, the language being protected, the current state of every framework and visual, and the next deliverables.

Then use [`BACKUP-MANIFEST.md`](BACKUP-MANIFEST.md) as the map of the repository.

Use [`OPEN-WORK-AND-NEXT-STEPS.md`](OPEN-WORK-AND-NEXT-STEPS.md) for the living roadmap from diagnosis to practical, life-giving systems.

## The heartbeat

> **Everything we create must be Christ-centered—not merely Christ-adjacent.**

Jesus remains the standard—not church trends, organizational growth, attendance, branding, efficiency, or financial success. Better does not mean bigger, busier, richer, or more impressive. It means healthier.
