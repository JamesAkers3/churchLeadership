## Finding and reproducing earlier work

Historical notes may still record a PDF's original `output/pdf/` path. When an older file is absent there, look for the same filename in this archive. Production builders and review renders remain in their original locations; older builders retain their historical output paths and may recreate an older PDF in the main folder if deliberately rerun. The current Formation Gap v5 and Dim v5 verification scripts now read their archived comparison PDFs and pass after the move. No PDF content, artwork, font or builder was changed by this cleanup.

Version numbers belong in filenames and PDF metadata only. They should not appear on the face of a PDF.
